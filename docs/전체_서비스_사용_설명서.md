# 1. 서비스 개요

## 1.1 서비스 소개

M&K 사무소 일본 진출 운영 시스템은 일본 진출을 준비하는 기업이 기초 상담부터 전문가 상담까지 필요한 업무를 한 곳에서 진행할 수 있도록 지원하는 웹 서비스입니다.

사용자는 AI 챗봇으로 일본 법인 설립, 세무·회계, 비자, 노무 등에 관한 기초 질문을 정리할 수 있습니다. 이후 히어링 시트에 회사 정보를 입력하고, 필요한 자료를 제출한 뒤, 전문가 상담을 신청할 수 있습니다.

관리자는 상담 예약과 사용자 자료를 확인하고, 상담 일정을 승인하거나 조정합니다. 또한 AI 챗봇이 참고하는 지식자료를 분야별로 관리할 수 있습니다.

## 1.2 주요 기능

### 사용자 기능

- 회원가입 및 로그인
- 한국어·영어·일본어 화면 전환
- AI 기초 상담
- 법인 설립 히어링 시트 작성
- 입력 내용 및 필요 서류 확인
- 전문가 상담 예약 신청
- 상담 승인 상태 및 일정 확인
- 관리자와 상담 메시지 교환
- 상담용 파일 업로드·미리보기·다운로드·삭제
- 마이페이지 진행 현황 및 챗봇 대화 내역 확인

### 관리자 기능

- 전체 예약 일정 조회
- 상담 신청 승인 및 불허
- 운영 불가 시간 차단 및 해제
- 사용자 검색 및 상세정보 조회
- 사용자별 상담, 메시지, 파일, 챗봇 기록 확인
- 사용자 파일 업로드·미리보기·다운로드·삭제
- 관리자용 AI 챗봇 이용
- AI 지식자료 업로드 및 상태 관리
- 분야별 벡터 DB 제작

## 1.3 권한 구분

| 구분 | 이용 대상 | 주요 접근 화면 |
|---|---|---|
| 비회원 | 서비스 방문자 | 홈, 서비스 소개, 로그인, 회원가입 |
| 사용자 | 상담을 신청하는 고객 | AI 상담, 히어링 시트, 상담 예약, 마이페이지 |
| 관리자 | 상담 및 자료를 운영하는 담당자 | 예약 현황, 사용자 목록, 관리자 챗봇, 자료 관리 |

사용자 전용 기능과 관리자 기능은 로그인 후 부여된 권한에 따라 표시됩니다. 권한이 없는 화면에는 접근할 수 없습니다.

## 1.4 전체 이용 흐름

1. 회원가입 또는 로그인을 진행합니다.
2. AI 챗봇으로 일본 진출 관련 기초 질문을 정리합니다.
3. 히어링 시트에 법인 설립 정보를 입력합니다.
4. 최종 입력 내용과 필요 서류를 확인한 뒤 전송합니다.
5. 상담 분야, 전문가, 희망 일정을 선택하여 상담을 신청합니다.
6. 마이페이지에서 필요한 파일을 제출합니다.
7. 관리자가 상담 신청과 제출 자료를 검토합니다.
8. 관리자가 상담 일정을 승인하거나 불허합니다.
9. 사용자는 상담 내역에서 결과를 확인하고 필요한 내용을 관리자와 주고받습니다.

## 1.5 지원 언어

서비스는 다음 언어를 지원합니다.

- 한국어(KO)
- 일본어(JP)
- 영어(EN)

홈 화면 또는 메뉴의 언어 설정에서 원하는 언어를 선택할 수 있습니다. 언어를 변경하면 화면이 새로고침될 수 있습니다.

## 1.6 이용 시 공통 주의사항

- AI 챗봇의 답변은 상담 준비를 위한 참고 정보입니다.
- 최종 법률·세무·회계 판단은 반드시 담당 전문가와 확인해야 합니다.
- 회사 정보와 제출 서류에는 민감한 내용이 포함될 수 있으므로 공용 기기에서는 사용 후 반드시 로그아웃합니다.
- 브라우저를 닫기 전 전송 또는 업로드 완료 메시지가 표시되었는지 확인합니다.
- 삭제한 예약 내역이나 파일은 복구가 어려울 수 있으므로 삭제 전 대상을 다시 확인합니다.

# 2. 사용자 입장 사용 설명서

## 2.1 홈 화면 이용하기

홈 화면에서는 서비스 소개, 진행 방식, 전문가 정보, 운영 방식 및 대표 견적을 확인할 수 있습니다.

상단 메뉴의 주요 항목은 다음과 같습니다.

- **서비스**: AI 상담, 히어링 시트 및 전문가 상담 기능 안내
- **진행 방식**: 일본 진출 준비 절차 안내
- **전문가**: 상담 가능한 전문가 정보
- **운영 방식**: 문서 구조화, 다국어 지원 및 상담 연계 방식 안내
- **상담 예약**: 전문가 상담 신청 화면으로 이동
- **마이 페이지**: 로그인한 사용자의 예약, 파일 및 진행 현황 확인

홈 화면의 질문 입력란에 질문을 작성하고 **AI 상담**을 누르면 챗봇으로 이동합니다. 로그인하지 않은 경우 로그인 화면이 먼저 표시되며, 로그인 후 작성한 질문을 이어서 진행할 수 있습니다.

## 2.2 회원가입

### 일반 회원가입

1. 홈 화면에서 **시작하기** 또는 로그인 화면의 **회원가입**을 선택합니다.
2. 다음 정보를 입력합니다.
   - 업무 이메일
   - 이름
   - 로그인에 사용할 아이디
   - 비밀번호
3. 서비스 이용을 위한 계정 생성 동의 항목을 선택합니다.
4. **M&K 계정 생성**을 누릅니다.
5. 가입 완료 후 자동 로그인되거나 로그인 화면으로 이동합니다.

모든 입력 항목과 계정 생성 동의는 필수입니다. 이미 사용 중인 아이디나 이메일인 경우 안내 메시지를 확인하고 다른 정보를 입력합니다.

### Google 계정으로 가입

1. 회원가입 화면에서 Google 계정 버튼을 선택합니다.
2. 사용할 Google 계정을 선택하고 인증을 완료합니다.
3. 인증에 성공하면 사용자 계정으로 로그인됩니다.

## 2.3 로그인과 로그아웃

### 로그인

1. 홈 화면의 **로그인**을 선택합니다.
2. 아이디와 비밀번호를 입력합니다.
3. **로그인**을 누릅니다.

Google 계정을 이용하는 경우 Google 로그인 버튼을 선택합니다. 아이디나 비밀번호가 맞지 않으면 입력 내용을 확인한 뒤 다시 시도합니다.

### 로그아웃

1. 상단 메뉴에서 **로그아웃**을 선택합니다.
2. 확인 창에서 로그아웃을 승인합니다.
3. 로그아웃되면 홈 화면으로 이동합니다.

작성 중인 히어링 시트 초안은 사용자별로 보관되지만, 공용 기기에서는 로그아웃 여부를 반드시 확인합니다.

## 2.4 AI 기초 상담 이용하기

AI 상담은 일본 법인 설립, 세무, 회계, 비자, 노무 및 정관 작성에 관한 기초 질문을 정리하는 기능입니다.

1. 홈 화면의 질문 입력란을 이용하거나 메뉴에서 AI 상담 화면으로 이동합니다.
2. 질문 입력란에 상담할 내용을 구체적으로 작성합니다.
3. **전송**을 누릅니다.
4. 답변이 생성될 때까지 기다립니다.
5. 추가 질문이 있으면 같은 방식으로 이어서 입력합니다.

화면의 자주 묻는 질문을 선택하면 예시 질문을 바로 사용할 수 있습니다. 새로운 주제로 다시 시작하려면 **대화 초기화**를 선택합니다.

AI 상담 화면에서는 다음 단계로 **히어링 시트 작성** 또는 **전문가 상담 예약**을 선택할 수 있습니다. 최근 질문과 답변은 마이페이지의 **챗봇 대화 내역**에서 확인할 수 있습니다.

> AI 답변은 참고용입니다. 실제 계약, 신고, 법률 또는 세무 의사결정은 전문가 검토 후 확정합니다.

## 2.5 히어링 시트 작성하기

히어링 시트는 일본 법인 설립과 정관 초안 작성에 필요한 정보를 단계별로 입력하는 화면입니다. 로그인한 사용자만 이용할 수 있습니다.

### 1단계: 회사 정보

다음 기본 정보를 입력합니다.

- 상호
- 영문 상호
- 본점 소재지

### 2단계: 사업 정보

회사의 사업 목적을 입력합니다. 사업 목적이 여러 개인 경우 항목을 추가하여 각각 입력할 수 있습니다.

### 3단계: 금융·자본 정보

다음 정보를 입력합니다.

- 자본금 납입 은행과 지점
- 출자 재산 가액(자본금)
- 발행가능주식총수
- 설립 시 발행주식수

입력한 금액과 주식 수가 실제 설립 계획과 일치하는지 확인합니다.

### 4단계: 주주 정보

주주 또는 출자 참여자의 다음 정보를 입력합니다.

- 이름
- 주소
- 출자금액
- 발기인 여부
- 출자자 여부

참여자가 여러 명이면 항목을 추가합니다. 발기인과 출자자 항목은 복수로 선택할 수 있습니다.

### 5단계: 임원 정보

다음 임원 정보를 입력합니다.

- 대표이사 성명
- 이사의 임기
- 추가 이사의 성명 및 로마자 성명

추가 이사는 필요한 경우에만 등록합니다.

### 단계 이동과 임시 저장

- **다음 단계로 이동**: 현재 단계의 필수 입력값을 확인하고 다음 단계로 이동합니다.
- **이전**: 앞 단계로 돌아갑니다.
- **입력 내용 요약 보기**: 지금까지 입력한 주요 내용을 확인합니다.
- **최종 내용 확인**: 모든 단계의 입력 내용을 검토하는 화면으로 이동합니다.

입력 중인 초안은 브라우저에 사용자별로 저장됩니다. 다만 다른 기기나 브라우저에서는 동일한 초안이 표시되지 않을 수 있으므로 중요한 내용은 최종 전송까지 완료하는 것이 좋습니다.

## 2.6 히어링 시트 최종 확인 및 전송

최종 확인 화면에서는 다음 내용을 구역별로 검토합니다.

- 회사 정보
- 사업 정보
- 금융·자본 정보
- 주주 정보
- 임원 정보
- 법인 설립에 필요한 서류

1. 각 항목이 실제 회사 설립 계획과 일치하는지 확인합니다.
2. 수정할 내용이 있으면 히어링 시트로 돌아가 수정합니다.
3. 필요한 서류 안내를 확인합니다.
4. 확인 항목을 선택한 뒤 전송 버튼을 누릅니다.
5. 정상 전송 완료 메시지를 확인합니다.

필수 입력값이 누락되었거나 값의 관계가 맞지 않으면 오류 항목이 안내됩니다. 안내된 항목을 수정한 후 다시 전송합니다.

## 2.7 전문가 상담 예약하기

상담 예약은 신청 즉시 확정되는 방식이 아닙니다. 사용자가 가능한 시간을 제안하면 관리자가 확인한 뒤 승인 또는 불허 처리합니다.

### 1단계: 기본 정보와 상담 방식

1. 상담 분야를 선택합니다.
2. 상담 방식을 선택합니다.
   - 온라인 상담: Zoom 또는 Google Meet
   - 오프라인 상담: 오사카 사무소 방문
3. 신청자 정보를 입력합니다.
   - 이름
   - 회사명
   - 연락처
   - 이메일
   - 직책
4. **다음 단계**를 누릅니다.

### 2단계: 전문가 선택

선택한 상담 분야에 맞는 전문가 목록에서 원하는 전문가를 선택합니다. 전문가의 담당 분야, 소개, 전문 영역 및 평점을 확인할 수 있습니다.

### 3단계: 일정 선택

1. 달력에서 상담 희망 날짜를 선택합니다.
2. 시간표에서 가능한 시간대를 클릭하거나 드래그합니다.
3. 필요한 경우 여러 개의 희망 시간 범위를 추가합니다.
4. 선택한 상담 일정을 확인합니다.
5. **다음 단계로 이동**을 누릅니다.

원활한 상담을 위해 90분에서 120분 정도의 시간을 선택하는 것을 권장합니다. 이미 승인되었거나 관리자가 차단한 시간은 선택할 수 없으며, 지난 날짜도 예약할 수 없습니다.

### 4단계: 예약 신청 내용 확인

1. 상담 분야, 상담 방식, 전문가, 신청자 및 제안 일정을 확인합니다.
2. 상담에서 다루고 싶은 내용이 있으면 **추가 요청 사항**에 입력합니다.
3. **예약 내용 확인하기**를 누릅니다.
4. 확인 창에서 최종 내용을 검토합니다.
5. 상담 신청을 제출합니다.

신청 후에는 전문가 또는 관리자의 검토가 진행됩니다. 결과는 마이페이지의 **내 상담 내역**에서 확인합니다.

## 2.8 마이페이지 이용하기

마이페이지는 상담 예약, 제출 파일, 챗봇 기록 및 전체 준비 상태를 확인하는 사용자 전용 화면입니다.

### 다음 상담 일정

가장 가까운 예정 상담의 날짜, 시간, 분야 및 승인 상태가 표시됩니다. **상세보기**를 누르면 예약 정보를 확인할 수 있고, **일정 신청**을 누르면 새 상담을 예약할 수 있습니다.

### 진행 현황

다음 5단계의 완료 여부가 실제 이용 기록에 따라 자동으로 반영됩니다.

1. 사전 정보 전송
2. 상담 신청 완료
3. 자료 업로드
4. 전문가 검토 대기
5. 상담 일정 확정

### 챗봇 대화 내역

최근 AI 상담 질문과 답변을 확인할 수 있습니다. 질문을 선택하면 해당 답변이 펼쳐집니다. **새 상담 시작**을 선택하면 AI 상담 화면으로 이동합니다.

## 2.9 내 상담 내역 관리하기

**마이페이지 → 내 상담 내역**에서 다음 정보를 확인할 수 있습니다.

- 전체 상담 수
- 예정 상담 수
- 승인 대기 수
- 승인 완료 수
- 상담 날짜와 시간
- 상담 분야
- 예약 번호와 신청일
- 불허 또는 취소 사유

검색창에서 분야 또는 날짜를 검색할 수 있으며, 기간과 상태를 기준으로 목록을 필터링할 수 있습니다.

### 예약 상태

| 상태 | 의미 |
|---|---|
| 승인 대기 | 관리자가 아직 상담 일정을 검토 중인 상태 |
| 승인 완료 | 상담 일정이 확정된 상태 |
| 불허 | 관리자가 신청을 승인하지 않은 상태 |
| 취소 완료 | 사용자가 상담을 취소한 상태 |

### 상담 취소 및 내역 삭제

- 취소 가능한 상담에는 **상담 취소** 버튼이 표시됩니다.
- 취소 또는 불허 등 종료된 상담에는 **내역 삭제** 버튼이 표시될 수 있습니다.
- 취소 또는 삭제 전에 예약 번호와 일정을 다시 확인합니다.

### 상담 상세정보와 메시지

**상세보기**를 누르면 상담 분야, 상담 일시, 상태, 신청·승인 일시, 예약 번호 및 처리 사유를 확인할 수 있습니다.

상담 메시지 영역에서 관리자에게 추가 내용을 보낼 수 있습니다. 메시지를 입력한 뒤 **전송**을 누르고, 목록에 정상적으로 표시되는지 확인합니다.

## 2.10 내 파일 관리하기

**마이페이지 → 내 파일 관리**에서 상담과 일본 진출 준비에 필요한 자료를 제출하고 관리할 수 있습니다.

### 필수 서류 확인

**필수 서류 안내**에서 필요한 문서와 준비 기준을 확인합니다. 안내된 서류는 원칙적으로 발급일로부터 1개월 이내의 자료를 준비합니다.

### 파일 업로드

1. 파일 업로드 영역을 눌러 제출할 파일을 선택합니다.
2. **문서 분류**를 선택합니다.
   - 필수 서류에 해당하면 안내된 항목을 선택합니다.
   - 해당하지 않으면 일반 제출 문서를 선택합니다.
3. 사용자와 관리자에게 표시할 **파일 명칭**을 입력합니다.
4. 파일의 목적을 알 수 있도록 **파일 설명**을 입력합니다.
5. **업로드**를 누릅니다.
6. 업로드 완료 메시지와 목록 등록 여부를 확인합니다.

필수 서류 종류를 선택하여 업로드하면 준비 현황에 자동으로 반영됩니다.

### 업로드 파일 관리

업로드된 파일 목록에서 다음 작업을 할 수 있습니다.

- **미리보기**: 새 화면에서 파일 내용 확인
- **다운로드**: 파일을 현재 기기로 저장
- **삭제**: 제출 파일을 목록과 저장소에서 삭제
- **새로고침**: 서버의 최신 파일 목록 다시 불러오기

잘못된 파일을 업로드한 경우 파일명과 설명을 확인한 후 삭제하고 다시 업로드합니다.

# 3. 관리자 입장 사용 설명서

## 3.1 관리자 화면 접속

1. 관리자 권한이 부여된 계정으로 로그인합니다.
2. 홈 화면에서 **관리자 페이지**를 선택합니다.
3. 기본 관리자 화면인 **예약 현황 관리**로 이동합니다.

일반 사용자 계정으로는 관리자 화면에 접근할 수 없습니다.

## 3.2 관리자 메뉴 구성

관리자 화면의 왼쪽 메뉴는 다음과 같습니다.

- **예약 현황 관리**
- **사용자 목록**
- **관리자 챗봇**
- **PDF 업로드 및 자료 목록**
- **언어 설정**
- **로그아웃**

좁은 화면에서는 메뉴가 접혀 표시될 수 있습니다.

## 3.3 예약 현황 관리

예약 현황 관리에서는 전체 상담 신청과 확정 일정을 달력 및 시간표로 확인합니다.

### 일정 조회

- 날짜 또는 주간 이동 버튼으로 조회 기간을 변경합니다.
- 새로고침 기능을 이용해 최신 예약 정보를 다시 불러옵니다.
- 시간표에서 사용자 제안 시간, 차단 시간 및 확정 시간을 구분하여 확인합니다.

### 상담 신청 상세 확인

상담 신청을 선택하면 다음 정보를 확인할 수 있습니다.

- 신청자 및 회사 정보
- 상담 분야와 상담 방식
- 연락처
- 신청 일시
- 사용자가 제안한 상담 가능 시간
- 추가 요청 사항
- 현재 승인 상태

### 상담 승인

1. 승인할 상담 신청을 선택합니다.
2. 사용자가 제안한 시간 범위 중 확정할 시간을 선택합니다.
3. **승인** 또는 상담 시간 확정 기능을 선택합니다.
4. 확인 창의 내용을 검토한 뒤 승인합니다.
5. 확정된 시간이 시간표에 반영되었는지 확인합니다.

승인 완료 후 사용자의 상담 상태가 **승인 완료**로 변경됩니다.

### 상담 불허

1. 불허할 상담 신청을 선택합니다.
2. 불허 기능을 선택합니다.
3. 확인 창에서 대상 상담이 맞는지 확인합니다.
4. 불허 처리를 완료합니다.

불허 결과와 사유는 사용자 상담 내역에 표시될 수 있으므로, 필요한 경우 사용자가 이해할 수 있는 표현으로 사유를 작성합니다.

### 일정 차단 및 해제

내부 회의, 휴무 또는 점검 등으로 상담을 받을 수 없는 시간을 차단할 수 있습니다.

1. 시간표에서 차단할 시간 범위를 선택합니다.
2. **일정 차단**을 선택합니다.
3. 차단 사유를 입력합니다.
4. 확인 후 저장합니다.

차단된 시간을 다시 사용할 경우 해당 일정을 선택하고 **차단 해제**를 실행합니다. 이미 승인된 상담과 시간이 겹치지 않는지 먼저 확인합니다.

## 3.4 사용자 목록

사용자 목록에서는 가입한 사용자를 조회하고 상세 화면으로 이동할 수 있습니다.

### 사용자 검색

1. 검색창에 이름, 이메일 또는 UID를 입력합니다.
2. 검색 결과에서 사용자를 확인합니다.
3. 필요한 경우 새로고침 버튼으로 최신 목록을 불러옵니다.
4. 사용자를 선택하여 상세 화면으로 이동합니다.

목록이 여러 페이지인 경우 하단의 페이지 이동 기능을 이용합니다.

## 3.5 사용자 상세정보 관리

사용자 상세 화면에서는 한 사용자의 상담과 제출 자료를 통합하여 확인합니다.

### 사용자 기본정보

- 이름
- 이메일
- 사용자 식별정보

### 상담 신청 내역

상담 목록에서 신청 상태, 회사명, 분야 및 제안 시간을 확인합니다. 상담을 선택하면 주간 시간표와 상세 정보가 표시됩니다.

상세 화면에서 다음 내용을 확인할 수 있습니다.

- 회사 이름
- 상담 분야
- 상담 유형
- 상담 상태
- 연락처
- 신청 시간
- 사용자가 제안한 시간 범위
- 고객 추가 요청 사항

### 사용자와 메시지 교환

상담 상세 화면의 **상담 메모 및 채팅**에서 사용자와 추가 내용을 주고받을 수 있습니다.

1. 기존 메시지와 고객 요청 사항을 확인합니다.
2. 입력란에 전달할 내용을 작성합니다.
3. **전송**을 누릅니다.
4. 메시지 목록에 정상적으로 등록되었는지 확인합니다.

개인정보나 확정되지 않은 법률·세무 판단을 메시지로 전달하지 않도록 주의합니다.

### 사용자 파일 관리

사용자가 업로드한 파일의 파일명, 용량, 업로드 시간 및 설명을 확인할 수 있습니다.

관리자는 다음 작업을 할 수 있습니다.

- 사용자를 대신하여 파일 업로드
- 파일 미리보기
- 파일 다운로드
- 파일 삭제
- 목록 새로고침

삭제 전 사용자와 파일명을 다시 확인합니다. 다른 사용자의 파일을 잘못 삭제하지 않도록 주의합니다.

### 사용자 챗봇 대화 내역

사용자의 최근 AI 질문과 답변을 확인할 수 있습니다. 각 질문을 선택하면 답변이 펼쳐집니다. 기록이 최신 상태가 아니면 **새로고침**을 선택합니다.

챗봇 기록은 상담 준비를 위한 참고 자료로만 사용하고, 사용자의 의도를 단정하지 않습니다.

## 3.6 관리자 챗봇

관리자 챗봇은 상담 운영과 자료 검토를 보조하는 AI 기능입니다.

1. 왼쪽 메뉴에서 **관리자 챗봇**을 선택합니다.
2. 질문 입력란에 상담 관련 질문을 작성합니다.
3. 전송 버튼을 누릅니다.
4. 생성된 답변과 참고 정보를 확인합니다.
5. 새 주제로 시작하려면 초기화 기능을 사용합니다.

화면의 사용량 영역에서는 최근 답변의 입력 토큰, 출력 토큰 및 전체 사용량을 확인할 수 있습니다.

> 관리자 챗봇 답변도 참고용입니다. 실제 고객 안내나 전문 판단에 사용하기 전 근거 문서와 담당 전문가의 확인이 필요합니다.

## 3.7 PDF 업로드 및 자료 목록

이 화면에서는 사용자 상담 챗봇이 참고하는 지식자료를 업로드하고 분야별로 관리합니다. 화면 이름은 PDF 업로드이지만 현재 다음 파일 형식을 지원합니다.

- PDF
- DOCX
- XLSX
- CSV
- TXT
- MD

### 자료 업로드

1. **분야 선택**에서 자료가 속한 카테고리를 선택합니다.
   - 통합
   - 인사
   - 노무
   - 회계
   - 법무
2. **파일 선택**을 눌러 자료를 선택합니다.
3. 선택한 파일명과 분야를 확인합니다.
4. **업로드**를 누릅니다.
5. 업로드 완료 메시지를 확인합니다.
6. 자료 목록을 새로고침하여 파일이 정상 등록되었는지 확인합니다.

자료의 실제 내용과 분야가 다르면 AI 답변의 정확도에 영향을 줄 수 있으므로 업로드 전 카테고리를 신중하게 선택합니다.

### 자료 상태 관리

등록된 자료는 다음 상태로 관리할 수 있습니다.

| 상태 | 용도 |
|---|---|
| 사용중 | 현재 AI 참고자료로 사용하는 문서 |
| 사용안함 | 일시적으로 AI 참고 대상에서 제외한 문서 |
| 예약 자료 | 향후 사용을 위해 등록한 문서 |
| 보관됨 | 운영에서 제외하고 기록 목적으로 보관하는 문서 |

상태 변경 시 확인 창에서 대상 파일과 변경할 상태를 다시 확인합니다.

### 자료 미리보기·다운로드·삭제

- **미리보기**: 임시 접근 링크를 열어 문서 내용 확인
- **다운로드**: 원본 문서를 기기로 저장
- **삭제**: 자료를 서버 저장소에서 삭제
- **새로고침**: 분야별 자료 목록 최신화

삭제는 AI 답변 근거에 영향을 줄 수 있습니다. 다른 자료로 대체되었는지 확인하고, 필요한 경우 먼저 보관 상태로 변경한 뒤 삭제 여부를 결정합니다.

### 벡터 DB 제작

업로드하거나 상태를 변경한 문서를 AI가 실제로 참고하도록 분야별 벡터 DB를 제작합니다.

1. 자료 목록에서 대상 분야를 선택합니다.
2. 해당 분야에 포함된 파일과 상태를 확인합니다.
3. **벡터 DB 제작**을 누릅니다.
4. 확인 창에서 실행을 승인합니다.
5. 제작 완료 결과를 확인합니다.

벡터 DB 제작 중에는 창을 닫거나 같은 작업을 반복 실행하지 않습니다. 잘못된 자료가 포함된 상태에서 제작하면 챗봇 답변에 반영될 수 있으므로 먼저 파일 목록과 상태를 검토합니다.

## 3.8 언어 설정과 로그아웃

### 언어 설정

1. 관리자 메뉴 하단의 **언어 설정**을 선택합니다.
2. 한국어, 일본어 또는 영어를 선택합니다.
3. 화면이 새로고침되면 선택한 언어가 적용되었는지 확인합니다.

### 로그아웃

1. 관리자 메뉴 하단의 **로그아웃**을 선택합니다.
2. 확인 창에서 로그아웃을 승인합니다.
3. 사용자 홈 화면으로 이동했는지 확인합니다.

관리자 계정은 사용자 개인정보와 제출 자료에 접근할 수 있으므로, 자리를 비우거나 공용 기기를 사용할 때 반드시 로그아웃합니다.

## 3.9 관리자 운영 점검표

### 매일 확인

- 새 상담 신청 및 승인 대기 건 확인
- 사용자 메시지 및 추가 요청 사항 확인
- 오늘과 다음 영업일 상담 일정 확인
- 차단 시간과 확정 일정의 중복 여부 확인

### 자료 변경 시 확인

- 파일명과 실제 문서 내용 일치 여부
- 분야 분류의 정확성
- 문서의 최신 버전 여부
- 사용 상태 설정 여부
- 벡터 DB 재제작 완료 여부

### 개인정보 보호

- 상담 목적에 필요한 범위에서만 사용자 정보 열람
- 사용자 파일을 개인 기기나 승인되지 않은 위치에 저장하지 않기
- 메시지에 민감정보를 불필요하게 반복 기재하지 않기
- 관리자 화면 사용 후 반드시 로그아웃하기

# 부록. 문제 발생 시 확인사항

## 로그인이 되지 않는 경우

- 아이디와 비밀번호의 공백 및 오타를 확인합니다.
- Google 로그인 사용 시 올바른 계정을 선택했는지 확인합니다.
- 브라우저를 새로고침한 후 다시 시도합니다.
- 문제가 계속되면 서비스 관리자에게 계정 상태 확인을 요청합니다.

## 화면이나 목록이 갱신되지 않는 경우

- 화면의 **새로고침** 버튼을 먼저 사용합니다.
- 네트워크 연결 상태를 확인합니다.
- 같은 작업을 반복 제출하기 전에 실제 목록에 등록되었는지 확인합니다.

## 파일 업로드가 되지 않는 경우

- 파일이 선택되었는지 확인합니다.
- 필수 파일명과 설명을 입력했는지 확인합니다.
- 관리자 지식자료는 지원 형식인지 확인합니다.
- 업로드가 완료될 때까지 창을 닫지 않습니다.

## 예약할 시간이 선택되지 않는 경우

- 상담 희망 날짜를 먼저 선택했는지 확인합니다.
- 지난 날짜가 아닌지 확인합니다.
- 해당 시간이 승인 완료 또는 차단 상태인지 확인합니다.
- 다른 날짜 또는 시간대를 선택합니다.

## AI 답변이 적절하지 않은 경우

- 질문에 국가, 업무 분야, 현재 상황 및 원하는 결과를 구체적으로 작성합니다.
- 중요한 판단은 답변만으로 결정하지 말고 전문가 상담을 신청합니다.
- 관리자는 근거 자료의 분야, 상태 및 벡터 DB 제작 여부를 확인합니다.
