- 작성 기준: 현재 웹 서비스 기능

# 1. 서비스 개요

## 1.1 서비스 소개

M&K 사무소 일본 진출 운영 시스템은 일본 진출을 준비하는 기업이 AI 기초 상담, 법인 설립 정보 작성, 자료 제출 및 전문가 상담 예약을 한 곳에서 진행할 수 있도록 지원하는 서비스입니다.

사용자는 AI 챗봇으로 궁금한 내용을 먼저 정리하고, 히어링 시트와 제출 자료를 준비한 뒤 전문가 상담을 신청할 수 있습니다. 관리자는 상담 신청과 사용자 자료를 확인하고 일정을 승인하며, 챗봇이 참고하는 지식자료를 관리합니다.

## 1.2 주요 기능

| 구분 | 주요 기능 |
|---|---|
| 사용자 | 회원가입·로그인, AI 상담, 히어링 시트, 상담 예약, 파일 제출, 진행 상태 확인 |
| 관리자 | 예약 승인·차단, 사용자 조회, 상담 메시지, 파일 관리, AI 지식자료 관리 |

## 1.3 전체 이용 흐름

1. 회원가입 또는 로그인
2. AI 챗봇을 통한 기초 상담
3. 히어링 시트 작성 및 전송
4. 전문가 상담 예약 신청
5. 상담용 파일 제출
6. 관리자 검토 및 일정 승인
7. 마이페이지에서 결과 확인

서비스는 한국어, 일본어, 영어를 지원합니다. 화면의 언어 설정에서 원하는 언어를 선택할 수 있습니다.

# 2. 사용자 입장 사용 설명서

## 2.1 회원가입 및 로그인

### 회원가입

1. 홈 화면에서 **시작하기**를 선택합니다.
2. 이메일, 이름, 아이디 및 비밀번호를 입력합니다.
3. 계정 생성 동의 항목을 선택합니다.
4. **M&K 계정 생성**을 누릅니다.

Google 계정으로도 가입할 수 있습니다. 가입이 완료되면 자동 로그인되거나 로그인 화면으로 이동합니다.

### 로그인 및 로그아웃

로그인 화면에서 아이디와 비밀번호를 입력한 뒤 **로그인**을 누릅니다. 사용을 마친 후에는 상단 메뉴의 **로그아웃**을 선택합니다. 공용 기기에서는 반드시 로그아웃해 주세요.

## 2.2 AI 기초 상담

1. 홈 화면의 질문 입력란 또는 AI 상담 메뉴로 이동합니다.
2. 일본 법인 설립, 세무, 회계, 비자, 노무 등에 관한 질문을 입력합니다.
3. **전송**을 누르고 답변을 확인합니다.
4. 새로운 주제로 시작하려면 **대화 초기화**를 선택합니다.

최근 질문과 답변은 마이페이지의 **챗봇 대화 내역**에서 다시 확인할 수 있습니다.

## 2.3 히어링 시트 작성

히어링 시트는 일본 법인 설립과 정관 초안 작성에 필요한 정보를 정리하는 입력 양식입니다.

| 단계 | 입력 내용 |
|---|---|
| 1. 회사 정보 | 상호, 영문 상호, 본점 소재지 |
| 2. 사업 정보 | 회사의 사업 목적 |
| 3. 금융·자본 정보 | 자본금, 납입 은행, 주식 정보 |
| 4. 주주 | 주주·발기인 정보와 출자금액 |
| 5. 임원 정보 | 대표이사, 이사 및 임기 |

각 단계에서 필수 내용을 입력한 뒤 **다음 단계로 이동**을 누릅니다. 마지막 단계에서는 **최종 내용 확인**을 선택하고 전체 입력 내용을 검토한 후 전송합니다.

입력 중인 초안은 현재 브라우저에 저장될 수 있습니다. 다른 기기에서는 동일한 초안이 표시되지 않을 수 있으므로 최종 전송 여부를 확인해 주세요.

## 2.4 전문가 상담 예약

1. **상담 예약**으로 이동합니다.
2. 상담 분야와 상담 방식을 선택합니다.
   - 온라인: Zoom 또는 Google Meet
   - 오프라인: 오사카 사무소 방문
3. 신청자 정보를 입력합니다.
4. 원하는 전문가를 선택합니다.
5. 날짜와 가능한 시간대를 선택합니다.
6. 추가 요청 사항을 작성하고 신청 내용을 확인합니다.
7. 최종 확인 창에서 상담 신청을 제출합니다.

상담은 신청 즉시 확정되지 않습니다. 관리자가 신청 내용을 검토한 뒤 승인 또는 불허 처리하며, 결과는 **마이페이지 → 내 상담 내역**에서 확인할 수 있습니다.

## 2.5 마이페이지

마이페이지에서는 다음 정보를 한 곳에서 확인할 수 있습니다.

- 다음 상담 일정
- 상담 승인 상태
- 일본 진출 준비 진행 현황
- 제출 파일
- 최근 챗봇 대화 내역

### 내 상담 내역

상담 목록을 분야, 날짜 및 상태로 검색할 수 있습니다.

| 상태 | 의미 |
|---|---|
| 승인 대기 | 관리자가 상담을 검토 중인 상태 |
| 승인 완료 | 상담 일정이 확정된 상태 |
| 불허 | 상담 신청이 승인되지 않은 상태 |
| 취소 완료 | 사용자가 상담을 취소한 상태 |

**상세보기**에서 상담 일시, 신청·승인 일시, 처리 사유를 확인할 수 있습니다. 상담 메시지 입력란을 이용하면 관리자와 추가 내용을 주고받을 수 있습니다.

### 내 파일 관리

1. **마이페이지 → 내 파일 관리**로 이동합니다.
2. 필요한 경우 **필수 서류 안내**를 먼저 확인합니다.
3. 제출할 파일을 선택합니다.
4. 문서 분류, 파일 명칭 및 설명을 입력합니다.
5. **업로드**를 누르고 완료 메시지를 확인합니다.

업로드한 파일은 목록에서 미리보기, 다운로드 또는 삭제할 수 있습니다. 필수 서류는 안내된 유효기간과 발급 기준을 확인한 후 제출해 주세요.

# 3. 관리자 입장 사용 설명서

## 3.1 관리자 화면 접속

관리자 권한이 있는 계정으로 로그인한 뒤 홈 화면에서 **관리자 페이지**를 선택합니다. 일반 사용자 계정으로는 관리자 화면에 접근할 수 없습니다.

관리자 메뉴는 다음과 같습니다.

- 예약 현황 관리
- 사용자 목록
- 관리자 챗봇
- PDF 업로드 및 자료 목록

## 3.2 예약 현황 관리

예약 현황 화면에서는 전체 상담 신청과 확정 일정을 확인할 수 있습니다.

### 상담 승인 및 불허

1. 상담 신청을 선택합니다.
2. 신청자, 상담 분야, 연락처, 추가 요청 및 제안 시간을 확인합니다.
3. 승인할 시간 범위를 선택한 뒤 상담을 승인합니다.
4. 승인할 수 없는 경우 신청을 불허하고 필요한 사유를 남깁니다.

승인 결과는 사용자의 상담 내역에 반영됩니다. 처리 전 신청자와 날짜를 다시 확인해 주세요.

### 일정 차단

내부 회의, 휴무 등 상담이 불가능한 경우 시간표에서 범위를 선택하고 **일정 차단**을 실행합니다. 차단 사유를 입력한 뒤 저장하며, 다시 사용할 시간은 **차단 해제**로 복구합니다.

## 3.3 사용자 조회 및 상담 관리

**사용자 목록**에서 이름, 이메일 또는 UID로 사용자를 검색한 뒤 상세 화면으로 이동합니다.

사용자 상세 화면에서는 다음 정보를 확인할 수 있습니다.

- 사용자 기본정보
- 상담 신청 및 승인 상태
- 상담 가능 시간과 추가 요청
- 사용자와 주고받은 메시지
- 사용자가 제출한 파일
- 최근 챗봇 대화 내역

관리자는 사용자와 상담 메시지를 주고받거나, 필요한 파일을 대신 업로드할 수 있습니다. 파일 삭제 전에는 사용자와 파일명을 반드시 다시 확인합니다.

## 3.4 관리자 챗봇

관리자 챗봇은 등록된 자료를 참고하여 상담 운영과 문서 검토를 보조합니다.

1. **관리자 챗봇**으로 이동합니다.
2. 상담 관련 질문을 입력하고 전송합니다.
3. 답변과 참고자료를 확인합니다.
4. 고객에게 안내하기 전 근거 문서와 전문가 판단을 다시 확인합니다.

## 3.5 AI 지식자료 관리

**PDF 업로드 및 자료 목록**에서는 챗봇이 참고할 문서를 관리합니다. 지원 형식은 PDF, DOCX, XLSX, CSV, TXT 및 MD입니다.

### 자료 등록

1. 통합, 인사, 노무, 회계 또는 법무 분야를 선택합니다.
2. 파일을 선택하고 **업로드**를 누릅니다.
3. 자료 목록에서 정상 등록 여부를 확인합니다.

### 자료 상태

| 상태 | 의미 |
|---|---|
| 사용중 | 현재 AI가 참고하는 자료 |
| 사용안함 | 참고 대상에서 일시 제외한 자료 |
| 예약 자료 | 향후 사용을 위해 준비한 자료 |
| 보관됨 | 운영에서 제외하고 보관하는 자료 |

자료를 추가하거나 상태를 변경한 후에는 대상 분야를 선택하고 **벡터 DB 제작**을 실행합니다. 잘못된 자료가 AI 답변에 반영되지 않도록 파일 내용, 분야 및 상태를 먼저 확인해 주세요.

## 3.6 공통 주의사항

- 사용자 정보와 제출 파일은 상담에 필요한 범위에서만 확인합니다.
- 확정되지 않은 전문 판단을 사용자에게 단정적으로 전달하지 않습니다.
- 파일 삭제와 예약 처리는 실행 전 대상을 다시 확인합니다.
- 관리자 화면 사용 후에는 반드시 로그아웃합니다.

---

## 문제 발생 시

- 로그인이 되지 않으면 아이디·비밀번호와 계정 권한을 확인합니다.
- 예약 또는 파일 목록이 갱신되지 않으면 화면의 **새로고침**을 사용합니다.
- 파일이 업로드되지 않으면 파일 선택, 필수 입력값 및 지원 형식을 확인합니다.
- 예약 시간이 선택되지 않으면 지난 날짜 또는 차단·승인된 시간인지 확인합니다.
- 문제가 계속되면 오류 메시지와 발생 화면을 함께 기록하여 서비스 관리자에게 전달합니다.
