# CapsDol 회계사 미팅용 서비스 검증 문서

## 1. 미팅 목적

현재 배포된 CapsDol 서비스(https://capsdol.vercel.app/)를 기준으로, 일본 진출 지원 서비스가 실제 회계/세무 전문가 관점에서 적절한 흐름과 정보를 제공하는지 검증한다.

이번 미팅의 핵심은 디자인 평가가 아니라 다음 항목을 확인하는 것이다.

- 사용자가 상담 전에 입력해야 하는 정보가 충분한가
- AI 챗봇이 답변해도 되는 범위와 전문가에게 넘겨야 하는 범위는 어디까지인가
- 히어링 시트 항목이 실제 정관 작성 및 상담 준비에 적절한가
- 상담 예약 흐름이 실제 업무 프로세스와 맞는가
- 일본 진출 절차 설명이 회계/세무 관점에서 정확한가

## 2. 현재 서비스 한 줄 설명

CapsDol은 한국 기업 또는 창업자가 일본 진출 과정에서 필요한 법무, 세무, 회계, 노무 정보를 확인하고, 히어링 시트 작성과 상담 예약까지 이어갈 수 있도록 돕는 AI 기반 일본 진출 지원 플랫폼이다.

## 3. 현재 배포 서비스 기준 주요 기능

| 구분 | 기능 | 회계사에게 검증받을 포인트 |
|---|---|---|
| 메인페이지 | 일본 진출 서비스 소개 | 서비스 설명이 실제 고객에게 신뢰감을 주는가 |
| 챗봇 | 일본 진출 관련 질문 입력 | AI가 답변 가능한 주제와 위험한 주제 구분 필요 |
| 히어링 시트 | 법인 설립 관련 정보 입력 | 정관/상담 준비에 필요한 항목이 충분한가 |
| 정관 결과 | 입력 내용 기반 문서 형태 확인 | 실제 정관 초안으로 보기 적절한가 |
| 상담 예약 | 상담 분야, 날짜, 시간 선택 | 예약 전에 더 받아야 할 정보가 있는가 |
| 내 예약 | 예약 상태 확인 | 승인/거절/취소 상태 문구가 적절한가 |
| 관리자 페이지 | 예약 및 문서 관리 | 실제 운영자가 확인해야 할 정보가 충분한가 |

## 4. 회의 진행 순서

### 4.1 서비스 개요 설명

설명 예시:

> 현재 서비스는 일본 진출을 준비하는 한국 기업이 먼저 AI 챗봇으로 기본 정보를 확인하고, 히어링 시트를 작성해 회사 설립 정보를 정리한 뒤, 필요하면 전문가 상담을 예약하는 흐름으로 구성되어 있습니다.

### 4.2 화면 시연 순서

1. 메인페이지
2. 챗봇 질문 흐름
3. 히어링 시트 작성
4. 정관 결과 화면
5. 상담 예약 페이지
6. 내 예약 확인
7. 관리자 예약 관리

## 5. 회계사에게 반드시 물어볼 질문

### 5.1 일본 진출 절차 검증

1. 한국 기업이 일본에 진출할 때 일반적으로 가장 먼저 확인해야 하는 사항은 무엇인가요?
2. 현재 서비스의 흐름인 상담 및 사전 준비, 법인 설립, 세무/회계, 노무/사회보험 순서가 실제 업무 흐름과 맞나요?
3. 법인 설립 전에 고객에게 반드시 안내해야 할 리스크는 무엇인가요?
4. 일본 진출 준비자가 가장 자주 오해하는 부분은 무엇인가요?

### 5.2 히어링 시트 검증

1. 현재 항목인 상호, 사업 목적, 자본금, 은행, 발기인, 이사, 대표이사, 이사의 임기가 실제 상담 준비에 충분한가요?
2. 추가해야 할 항목이 있나요?
   - 본점 소재지
   - 회계연도
   - 주식 수
   - 1주 금액
   - 사업 개시 예정일
   - 일본 내 대표자 유무
   - 계좌 개설 가능성
3. 사용자가 직접 입력하기 어려운 항목은 무엇인가요?
4. 입력 예시를 제공해야 하는 항목은 무엇인가요?
5. 이 히어링 시트를 상담 전에 받으면 실제 상담 시간이 줄어들까요?

### 5.3 챗봇 답변 범위 검증

1. AI가 자동으로 답변해도 되는 질문은 어떤 범위인가요?
2. AI가 답변하면 위험한 질문은 어떤 범위인가요?
3. 세무/회계 관련 답변에서 반드시 붙여야 하는 주의 문구는 무엇인가요?
4. 챗봇이 답변하지 말고 상담 예약으로 넘겨야 하는 조건은 무엇인가요?
5. 답변 하단에 참고 문서나 출처를 보여주는 것이 신뢰도에 도움이 될까요?

### 5.4 상담 예약 검증

1. 상담 예약 전에 회사명, 연락처, 상담 분야, 날짜, 시간 외에 더 필요한 정보가 있나요?
2. 상담 분야는 법무, 회계, 노무, 인사 정도로 충분한가요?
3. 예약 신청 후 사용자가 어떤 안내를 받아야 하나요?
4. 승인 대기, 승인 완료, 거절, 취소 상태를 어떤 문구로 보여주는 것이 좋을까요?
5. 상담 전 사용자가 준비해야 할 서류 목록은 무엇인가요?

### 5.5 신뢰 요소 검증

1. 실제 고객이 사이트를 봤을 때 신뢰하기 위해 필요한 정보는 무엇인가요?
2. 전문가 약력은 어느 정도까지 공개하는 것이 적절한가요?
3. 요금 범위는 메인페이지에 보여주는 것이 좋을까요, 상담 후 안내하는 것이 좋을까요?
4. 개인정보 처리방침, 이용약관, AI 답변 면책 문구 중 가장 우선순위가 높은 것은 무엇인가요?

- 이 서비스가 실제 일본 진출 준비자의 문제를 해결하는가?
